# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Volunteers, event organizers, community partners, and sponsors who are registering for varcamp.

## Product Purpose
To provide a streamlined, engaging registration process for all levels of audiences (volunteers, organizers, partners, sponsors).

## Positioning
A tailored, engaging registration process specifically designed for varcamp participants.

## Operating Context
Users will be accessing this from a web browser to fill out a multi-step registration form (stepper-based), using their personal devices prior to the event.

## Capabilities and Constraints
- Web application (Next.js)
- Stepper-based form layout

## Brand Commitments
Must align with the existing varcamp web app styling and use the `reui` design system.

## Evidence on Hand
The existing volunteer page demonstrates the stepper form and ReUI components (`apps/register/app/2026/volunteer/page.tsx`).

## Product Principles
- Streamlined Experience: The registration must be fast and easy to navigate for all types of users.
- Engaging Design: The UI should be welcoming and visually engaging.
- Consistent Styling: Maintain strict alignment with the broader varcamp ecosystem using the `reui` design system.
